# 0.2.1

## First npm release

- Distribute compiled ESM, TypeScript declarations, documentation, and the database-grant SQL export; require Node.js 22 or later.
- Include revision history, optimistic edit conflicts, typed queries and projections, relation operations, and multilingual text helpers.
- Resolve typed models through a DAL instance using model handles or manifests.
- Publish through repository-owned GitHub Actions workflows with tested tarball integrity and provenance.

## Migrating from Git installs

- Replace the Git dependency with an exact npm version when ready: `npm install --save-exact rev-dal@0.2.0`. Existing root imports, exported `rev-dal/lib/*` subpaths, and the SQL export remain available.
- Compared with the consumers' previous Git pin (`ef55702`), declarations now enable strict null checks. Handle nullable results explicitly where TypeScript reports them.
- Transaction arguments must be checked-out PostgreSQL clients in an active transaction; passing a pool is rejected. Prefer `dal.transaction()`.
- This release adds no database migration or grant change. Applications still own their schemas.
- Consumer dependency upgrades and deployments are separate from this release.

## Publishing fix

- Normalize artifact paths before invoking npm so downloaded tarballs are published as local files.
- Version 0.2.0 was not published because its publishing command misinterpreted a relative path. This version is the first npm publication.
