# 0.2.2

## Release automation

- Allow up to five minutes for npm to process an accepted publication before verifying registry integrity and creating the tag and GitHub release.
- Keep polling without resubmitting the accepted package; document recovery if processing takes longer.
- Publish this release using GitHub Actions trusted publishing (OIDC), with no npm bootstrap token.

## Consumer compatibility

No runtime API, declaration, schema, or grant changes from 0.2.1. Consumer dependency updates and deployments remain separate.
